# 全國中小學校園通用 考試倒數計時時鐘系統（支援自訂校名與自訂校徽）

這是一個**完全開放、全校園通用**的考場專用倒數計時數字時鐘系統。適用於任何國小、國中、高中或大專院校，不僅支援投影機全螢幕高對比顯示、自動節次與下課跳轉、擬真學校西敏寺鐘聲，更**支援隨時自由修改學校名稱（如各校國小、國中）與更換校徽圖片**！

---

## 🌟 核心特色

### 1. 學校名稱自由修改（點擊即改）
- 點擊左上角的學校名稱（例如「嘉義市蘭潭國小」），即可直接輸入自訂校名（例如「臺北市立建國中學」、「高雄市立四維國小」等）。
- 修改後立即同步更新主畫面、分頁標題及匯出之考程設定檔，並自動儲存在瀏覽器本機空間（下次開啟維持自訂名稱）。

### 2. 學校校徽一鍵點擊更換
- 滑鼠移至左上角校徽圖示時，會顯示「📷 更換」，點擊即可挑選本機電腦上的校徽圖檔或班級標誌進行更換。
- 圖片採用本機 Base64 儲存技術，免架設伺服器也能永久保留，並隨時支援一鍵還原為預設校徽。

### 3. 學年度、學期別與考查名稱完全可自訂
- 點擊學年度標題列，即可自由切換：
  - 學年度（115、116、117...）
  - 學期別（上學期 / 下學期）
  - 考查名稱（第一次定期考查、第二次定期考查、期中評量、期末評量、畢業考查或自訂名稱）

### 4. 考程與科目範圍線上管理（支援下載與上傳更新）
- 點擊「**📅 考程管理**」：
  - 可直接在線上表格中編輯各年級、各節次科目與範圍。
  - 可新增/刪除考試日期天數（例如 11/3、11/4、1/15 等）。
  - 提供「**📥 下載考程範例檔 (JSON)**」供教務處統一規劃編輯。
  - 提供「**📤 上傳考程更新檔**」快速整校套用。

### 5. 智慧自動流水線倒數（含 20 分鐘大下課）
- **第一次下課**：預設 10 分鐘。
- **第二次下課**：預設 **20 分鐘（課間活動 / 大下課）**。
- 倒數至 00:00 自動鳴響鐘聲，並優雅自動接續下一節或下課！在設定中亦可自由調整各階段分鐘數。

### 6. Web Audio API 擬真校園鐘聲
- 包含經典西敏寺鐘聲、清新雙音、長鈴聲與最後 5 分鐘溫馨提醒音，完全離線合成。

### 7. 五大視覺主題
- 🌲 **校園清新綠**
- 🌌 **宇宙天文**（深邃星空科技感）
- 🌙 **考場投影專用**（深色超高對比）
- 🍂 **護眼暖色**（琥珀金）
- 🎓 **黑板粉筆風**（復古墨綠）
