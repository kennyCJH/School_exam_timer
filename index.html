  • 免安裝、免連網：在電腦資料夾中對著 index.html 雙擊滑鼠左鍵，即可直接於 Chrome、Edge 或任何瀏覽器開啟。

一、主畫面功能導覽

畫面區塊功能說明
🏫 蘭潭校徽與標題 左上角顯示學校官方校徽。點擊旁邊的學年度標題列（帶 ✏️ 筆圖示處），可直接自訂修改學年、學期與考查名稱。
🕒 現在標準時間 右上角即時顯示今日日期、星期與當前秒數，方便監考老師對時。
📅 考程條件選擇列 提供「考試日期」、「學生年級」、「考試節次」下拉選單，選取後立即載入對應科目的倒數與範圍。
🔄 自動接續開關 勾選後，當節倒數結束（00:00）將自動切換至下課休息倒數，下課結束後自動接續下一節考試。
📋 科目與範圍看板 顯示當前「考試科目」、「節次狀態（考試中 / 下課中 / 正常上課）」與詳細評量範圍。
⏱️ 數字時鐘與進度條 超大等寬字體顯示分與秒，並伴隨直覺的色彩進度條（考試中為紅色、下課中為藍色、小於5分鐘為警戒金黃色）。
📑 當日考程預覽軌 畫面底部以卡片列出當日所有節次與下課，點選任一卡片可直接切換至該節。

二、計時操作與時間微調控制

  • 開始 / 暫停：點選畫面中央「開始/暫停」按鈕，或按鍵盤 空白鍵 Space。
  • 重設時間：點選「🔄 重設」可將當前節次恢復至初始時間。
  • 時間彈性微調：
    • 若因發卷、試場說明或突發狀況需延後或加時，點選 +1 分 或 +5 分。
    • 需縮短時間，可點選 -1 分 或 -5 分。
  • 提前結束本節 🏁：若學生全數提前交卷或該節提早結束，點擊此按鈕將立即鳴響結束鐘聲並銜接下一個階段。

三、學年度、學期與考查名稱自訂

滑鼠直接點擊頂部標題列，在彈出的視窗中：

  • 學年度：可按 +1 / -1 或直接輸入數字（如 115、116 等）。
  • 學期別：下拉切換「上學期」或「下學期」。
  • 考查次別：可選擇「第一次定期考查」、「第二次定期考查」、「期中評量」、「期末評量」、「畢業考查」或勾選「自訂」輸入文字。

四、考程資料庫線上管理（匯入 / 匯出）

點擊頂部「📅 考程管理」按鈕：

  • 線上表格編輯：切換日期與年級，即可在表格內自由修改節次序號、節次名稱、科目與範圍，並可「➕ 新增節次」或「🗑️ 刪除列」。
  • ➕ 新增考試日期：可建立新的考試天數（例如 11/5 或 1/15）。
  • 📥 下載考程範例檔 (JSON)：匯出全校標準格式檔案，可在電腦中大量編輯。
  • 📤 上傳考程更新檔：將編輯完成的 JSON 檔上傳，立即套用至全校各年級。
  • 🔄 還原蘭潭預設課表：隨時一鍵還原為 115 學年度第一次定期考查官方課表。

五、鐘聲音效與主題外觀設定

點擊頂部「⚙️ 設定」按鈕：

  • 校園鐘聲選擇：
    • 🏫 西敏寺鐘聲（學校經典上/下課四音階鐘聲，溫柔優美）
    • 🔔 現代清脆雙音（清新 Ding-Dong 音）
    • ⏰ 電子長鈴聲（連續長音鈴響）
  • 作息時間彈性調整：每節考試時間（預設 40 分鐘）、一般下課時間（預設 10 分鐘）與第二次下課（課間大下課，預設 20 分鐘）均可自由自訂。
  • 剩餘 5 分鐘提醒音：勾選後將在最後 5 分鐘時播放輕柔叮咚音，提醒學生檢查畫卡與姓名座號。
  • 五大主題切換：
    • 🌲 蘭潭校園（湖光翠綠清新）
    • 🌌 宇宙天文（蘭潭星象深邃藍，星軌星雲科技感）
    • 🌙 考場投影專用（深色超高對比，投影清晰不刺眼）
    • 🍂 護眼暖色（琥珀專注金）
    • 🎓 黑板粉筆風（復古墨綠教室感）

七、常見問題與疑難排解 (FAQ)

  • Q1：到 00:00 為什麼沒有聲音？
    瀏覽器安全機制要求使用者進入網頁後至少有一次點擊互動；只需點擊網頁任意處、點擊「開始」或「試聽鐘聲」即可解鎖音效，並請確認電腦音量已打開。
  • Q2：更換其他教室電腦，設定會保留嗎？
    設定儲存在本機瀏覽器。若要轉移到其他教室，可點擊「考程管理」下載 JSON 檔，到另一台電腦上傳即可！
  • Q3：改亂了想重來怎麼辦？
    在「考程管理」點擊「還原蘭潭預設課表」，或在「設定」點擊「恢復原廠預設值」，即可瞬間恢復初始課表。
